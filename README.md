# Ya Agent

面向综合办公场景的 Agent 学习与产品原型项目。当前先验证一条具体工作流：为制造业数字化转型/出海服务团队整理客户访谈，并生成可核对的跟进简报草稿。

## 当前状态

- 产品和 MVP 文档已建立。
- 技术学习与原型路线：Python + LangChain + LangGraph；需要服务接口时再引入 FastAPI。
- Hermes Agent 保留作成熟系统的代码参考，不属于本项目源代码，也不是当前 MVP 的运行时。
- 尚未实现可运行的产品代码；用户痛点和产品价值仍需验证。

## MVP 概述

输入一份获准使用或脱敏的客户访谈记录，生成包含客户现状、明确需求、潜在问题、待确认事项、下一步行动和跟进邮件草稿的简报。关键内容应能回到原始材料；用户审核后再导出。首版不自动发送邮件或写入外部系统。

## 开发约定

遵循根目录 `AGENTS.md` 和 `docs/` 中的产品及技术决策。先完成一条可验证的端到端工作流，再扩展集成和自动化。
